\section{Motivation}
\label{sec:motivation}

The rapid growth of digital content platforms has fundamentally changed how users discover and consume information.
In the domain of books alone, some platforms now catalogue millions of titles, making recommendation an important problem at scale.
A normal user browsing million books definitely cannot explore all the options manually; a recommendation system therefore acts as an layer that suggests relevant items before the user makes a specific interactions.

Traditional recommendation approaches tend to be unimodal.
Collaborative filtering methods use patterns in user item interactions, but they do not consider the actual content or meaning of the items.
Content based methods encode item descriptions into dense vectors and retrieve semantically similar content, but are insensitive to the community level purchasing patterns that often drive discovery.
Neither class of method captures sequential intent, the fact that a user's most recent interactions often signal a current reading interest that differs from their long term profile.
This motivates the development of a dual mode architecture that combines both behavioural signals and sequential intent modelling within a unified recommendation pipeline.

A further practical challenge is language. In Vietnam and other multilingual markets, many users search in their native language, but most open source encoders are mainly trained on English and often perform poorly with Vietnamese text.
This gap prevents non English speakers from getting the same quality of search results compare to English speakers.
Improving multilingual retrieval is therefore not just a technical improvement, but also a matter of access to information.

Finally, real world systems must improve accuracy without reducing the quality of the user experience.
A recommendation API that takes more than one second to respond is unlikely to be adopted in an interactive application.
Techniques such as model quantisation, approximate nearest neighbour indexing, and response caching should be considered core design requirements for reducing latency.

This capstone project addresses these challenges by designing, building, and evaluating a multimodal recommendation system that combines Cleora graph embeddings with the DIF-SASRec sequential transformer, along with a multilingual BGE-M3 encoder and a search pipeline optimized for low latency.
The system is built on a modular data platform, and its ingestion, storage, and visualization components are also demonstrated through an air quality monitoring use case, showing that the underlying infrastructure can be applied to different domains.
