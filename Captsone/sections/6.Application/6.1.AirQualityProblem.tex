\section{Application Overview}
\label{sec:app_overview}

The deployed application is a multimodal book discovery platform that allows users to find books through natural-language text queries, image queries, or both, and to receive personalised recommendations that adapt to their interaction history.

The application serves three practical user needs.
First, catalogue scale: the index covers approximately 3 million book items, making unguided browsing impractical.
Second, language diversity: Vietnamese-speaking users can query the catalogue through the integrated NLLB-200 translation pipeline, which translates queries to English before encoding.
Third, adaptive personalisation: a cold-start user receives co-purchase-based suggestions from the Cleora graph immediately; once five click interactions accumulate, DIF-SASRec sequential recommendations engage automatically.

The full application stack is:
\begin{itemize}
    \item Frontend: React 19 + Vite 8 + Tailwind CSS, served at \texttt{http://localhost:5173}.
    \item Backend: FastAPI + uvicorn, served at \texttt{http://localhost:8000}. Seven route groups: \texttt{/search}, \texttt{/recommend}, \texttt{/interact}, \texttt{/profile}, \texttt{/auth}, \texttt{/ask\_llm}, \texttt{/health}.
    \item Infrastructure: MongoDB (\texttt{nba\_logs} database) and Redis (interaction write-queue), both provisioned via Docker Compose.
\end{itemize}

If the backend is unreachable, a dismissible error notification is displayed and the interface continues to present the most recently loaded data without breaking the user experience.
User identity is persisted in \texttt{localStorage} so that returning users bypass the login gate automatically.
