\chapter*{Abstract}

This report presents the design, implementation, and evaluation of a dual-mode multimodal book recommendation system.
The system addresses two distinct scenarios: proactive candidate generation based on long-term behavioural history, and intent-sensitive ranking based on recent interaction sequences.

Two complementary pipelines are proposed.
Pipeline~A retrieves candidates from a Cleora co-purchase graph embedding index and re-ranks them using a BGE-M3 semantic user profile.
Pipeline~B applies a DIF-SASRec transformer with decoupled content and category attention streams to model sequential reading intent, with a content veto filter to remove semantically unrelated candidates.
The final recommendations are formed by the union of the top outputs of both pipelines.

The system is evaluated on the Amazon Book Reviews dataset using a leave-one-out protocol.
The combined system achieves \textbf{HR@10 = 0.9736} and \textbf{NDCG@10 = 0.5571} — a 124\% improvement over the content-only baseline and more than $8\times$ over the prior GRU-SeqDQN approach.

An active search pipeline supports semantic retrieval over 3 million items via FAISS HNSW, BM25 re-ranking through RRF fusion, and NLLB-based Vietnamese query translation.
End-to-end search latency is reduced from 1{,}102\,ms to 59\,ms, an 18.6$\times$ improvement.
The system is deployed as a full-stack interactive book discovery application.
