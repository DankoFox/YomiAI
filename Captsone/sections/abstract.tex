\chapter*{Abstract}

This report describes the design, implementation, and evaluation of a multimodal book recommendation and search system built on the Amazon Books dataset.

The recommendation component has two independent pipelines. Pipeline~A retrieves candidates from a Cleora co-purchase graph embedding index and re-ranks them by cosine similarity to a BGE-M3 user profile vector. Pipeline~B uses a DIF-SASRec transformer with decoupled content and category attention streams to model sequential reading intent. The two pipelines capture largely distinct user cases and are presented side by side in the interface. Their performance is evaluated in Chapter~5.

The search pipeline handles text and image queries over 3 million items via FAISS HNSW, BM25 re-ranking through RRF fusion, and NLLB-based Vietnamese query translation. Warm-cache end-to-end latency is 59\,ms, down from 1{,}102\,ms in the prior system.

The system runs as a full-stack interactive book discovery application.
