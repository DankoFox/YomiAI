\subsection{Mode 1: Active Search}
\label{ssec:active}

Given a user query consisting of text $q_t$ and optionally an image $q_i$,
the system produces a ranked list via:

\paragraph{Multilingual query normalization.}
The system supports queries in 19 languages.
Lingua\footnote{\url{https://github.com/pemistahl/lingua-py}} detects source
language in under 1\,ms.
Non-English queries are translated by NLLB-200-Distilled-600M~\cite{costa2022nllb}
with greedy decoding and beam-search fallback when the greedy
output retains untranslated tokens. Translation results are cached (2\,048
entries); repeat queries cost 0\,ms.

\paragraph{Encoding.}
Text query: $\mathbf{e}_t = \bgem(q_t) \in \mathbb{R}^{1024}$.
Image query: $\mathbf{e}_i = \text{CLIP}(q_i) \in \mathbb{R}^{512}$.
BGE-M3 inference is cached (4\,096 entries); repeated queries skip GPU
inference and are served from CPU RAM in under 0.1\,ms.

\paragraph{Retrieval.}
FAISS~\cite{johnson2019faiss} HNSW~\cite{malkov2018efficient} search retrieves top-$K$ candidates from each index independently,
yielding ranked lists $L_t$ and $L_i$.
A BM25~\cite{robertson1994okapi} keyword search over tokenized titles and descriptions yields $L_k$.

\paragraph{Fusion.}
Reciprocal Rank Fusion (RRF)~\cite{cormack2009rrf} combines the three lists:
\begin{equation}
  s_{\text{RRF}}(d) = \sum_{r \in \{L_t, L_i, L_k\}}
  \frac{1}{k + \text{rank}_r(d)}, \quad k = 60.
  \label{eq:rrf}
\end{equation}
The top-$N$ items by $s_{\text{RRF}}$ are returned with metadata.

\subsection{Mode 2: Passive Recommendation}
\label{ssec:passive}

\subsubsection{Pipeline A: Behavioral Candidate Retrieval}
\label{sssec:pipelineA}

\begin{enumerate}
  \item \textbf{Behavioral scouting.} The user's 5 most recent interactions
        seed a multi-query search in the behavioral embedding space, yielding 50 candidates.
  \item \textbf{Content veto.} Each candidate is scored against the user's
        aggregated BGE-M3 and CLIP profile vectors.
        Candidates satisfying
        \[
          \max\!\bigl(
            \cos(\mathbf{e}^{\text{bge}}_c,\,\mathbf{p}^{\text{bge}}),\;
            \cos(\mathbf{e}^{\text{clip}}_c,\,\mathbf{p}^{\text{clip}})
          \bigr) < 0.3
        \]
        are discarded.
  \item \textbf{Ranking.} Survivors are ranked by cosine similarity to the
        aggregated profile and the top-$K$ are returned.
\end{enumerate}

\subsubsection{Pipeline B: Sequential Intent Scoring}
\label{sssec:pipelineB}

\begin{enumerate}
  \item \textbf{Candidate generation.} HNSW search on text embeddings of
        the user's recent items retrieves 200 candidates.
  \item \textbf{Content veto.} Same threshold as Pipeline A.
  \item \textbf{Sequential scoring.} DIF-SASRec scores each candidate as the
        predicted next item.
\end{enumerate}

\subsection{DIF-SASRec Model}
\label{ssec:difsasrec}

We adapt DIF-SASRec~\cite{xie2022difsr} to a content-ID-free setting,
representing each item as its BGE-M3 embedding.

\paragraph{Architecture.}
The model uses a linear content projection, 4 transformer blocks with
causal self-attention, a dual-stream attention mechanism decoupling content
and category streams, and a dot-product prediction head (12.4M parameters).

\paragraph{Training.}
Trained on 100k users (80/20 temporal split) with sampled
softmax~\cite{jean2015using} and AdamW. An auxiliary category loss
($\lambda = 0.1$) stabilizes genre-level understanding.

\paragraph{Online adaptation.}
At inference, each user's agent fine-tunes on a single interaction step per
request, enabling real-time personalization without full retraining.
