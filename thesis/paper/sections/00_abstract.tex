\begin{abstract}
NBA systems typically rely on structured transaction data and cannot use multimodal signals such as text, images, and interaction histories. They also lack a unified framework for query-driven retrieval and personalized recommendation. We propose a dual-mode multimodal NBA framework for active search and passive personalization in a single architecture. The framework combines multimodal retrieval with two complementary pipelines: a graph-based component for behavioral patterns and a sequential model for evolving user preferences, capturing semantic relevance, behavioral signals, and temporal dynamics.
On Amazon Books~\cite{hou2024amazon} (3.08M items, 100k users), the system achieves HR@10 of 0.9736, outperforming content-based baselines by 124\%, with complementary pipelines recovering each other’s missed predictions.
\end{abstract}
