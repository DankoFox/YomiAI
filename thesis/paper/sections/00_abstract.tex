\begin{abstract}
Next Best Action (NBA) recommendation systems typically rely on structured transaction data and cannot leverage multimodal signals such as text, images, and interaction histories for unified active search and passive recommendation. We propose a dual-mode multimodal NBA framework that bridges this gap within a single architecture. The system combines multilingual text and image retrieval (Mode~1) with two complementary pipelines for personalized recommendation (Mode~2): a graph-based component capturing behavioral co-purchase patterns from Cleora embeddings, and a sequential model (DIF-SASRec) based on BGE-M3 content embeddings for evolving user preferences. A shared temporally-weighted user profile bridges both modes and enables online adaptation. On Amazon Books~\cite{hou2024amazon} (3.08M items, 100k users), the system achieves HR@10 of 0.9736 and NDCG@10 of 0.5571, outperforming content-based baselines by 124\%, with complementary pipelines recovering 88.3\% and 72.3\% of each other's missed predictions. Warm-cache latency is 34\,ms, supporting real-time deployment.
\end{abstract}
