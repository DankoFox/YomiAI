YomiAI Flows / 04 · Pipeline A — Cleora

Pipeline A — Cleora · People Also Buy

Collaborative filtering via Cleora co-purchase graph embeddings. Uses behavioral proximity in embedding space to find items that users with similar purchase history also bought.

Candidate Funnel
Input
User Profile Vectors
Retrieve UserBehaviorProfile from UserProfileManager. Extract the aggregated profile vectors maintained via exponential decay over click history.
cleora_profile [1024] text_profile [1024] visual_profile [512]
~375k items
Cleora FAISS Search — Behavioral Candidates
retriever.get_behavioral_candidates(cleora_profile) → searches IndexFlatIP (375k Cleora co-purchase embeddings, 1024-dim). Returns nearest behavioral neighbors — items co-purchased by similar users. ≈200 candidates
+expansion
Seed Expansion
Take the last 5 recent_interactions (recently clicked items) as seed ASINs. For each seed: call get_behavioral_candidates(seed_embedding) to fetch co-purchase neighbors. Union with main candidates. ≈300–400 total
filtered
Content Veto — τ = 0.3
For each behavioral candidate: compute text_profile · item_text_vec AND visual_profile · item_clip_vec. Keep only items satisfying at least one threshold.
ranked
Rank by Text Score
Sort surviving candidates by text_profile · item_text_vec descending. Content-profile alignment as the final ranking signal.
top-10 ✓
Output — people_also_buy
Top-10 behaviorally similar + content-verified items. Deduplicated against recently seen items. Returned as people_also_buy in the recommendation response.
Content Veto Logic
A candidate passes the veto if it clears either threshold — not both. This ensures behaviorally interesting items aren't excluded for having low text similarity if they have visual similarity (e.g. illustrated books).
Text Condition
text_profile · item_text_vec ≥ 0.3
BGE-M3 [1024] cosine dot product between user's aggregated text profile and item's text embedding.
OR
Visual Condition
visual_profile · item_clip_vec ≥ 0.3
CLIP [512] cosine dot product between user's aggregated visual profile and item's CLIP embedding.
Detailed Step Trace
  • 1
    profile_manager.get_profile(user_id) — loads UserBehaviorProfile. Contains cleora_profile, text_profile, visual_profile, clicks deque (max 50), recent_interactions.
  • 2
    retriever.get_behavioral_candidates(cleora_profile, top_n) → IndexFlatIP.search() over 375k Cleora co-purchase embeddings → list of (asin, cleora_score) tuples.
  • 3
    Seed expansion: for each of the last 5 recent_interactions, fetch that item's Cleora embedding and call get_behavioral_candidates(). Union all candidate sets.
  • 4
    Content veto: recommend_engine.content_verify(candidates, text_profile, visual_profile, τ=0.3) — filters out semantically unrelated items. Fetches item vectors from retriever.text_flat and retriever.clip_index.
  • 5
    Sort survivors by text_profile @ item_text_vec descending. Slice top-10. Return as people_also_buy.
Cleora Embedding Source
cleora_embeddings.npz — 375k item embeddings trained via Cleora (Markov chain propagation on co-purchase interaction graph). Captures behavioral co-occurrence rather than content. Updated when CLEORA_REFIT_THRESHOLD interactions accumulate, then hot-swapped via retriever.reload_cleora() without server restart. User's cleora_profile is the exponential decay weighted mean of clicked items' Cleora vectors.
