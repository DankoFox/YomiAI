YomiAI Flows / 02 · Startup Sequence

Startup Sequence

Called once by FastAPI at boot via lifespan=lifespan in app/main.py. All services placed into AppContainer on app.state.container.

8-Step Initialization · app/core/lifespan.py
1
FAISS Indices
Loads bge_index_hnsw.faiss (1.7M vecs), bge_index_flat.faiss (3M vecs), clip_index_hnsw.faiss, and cleora_embeddings.npz (375k) into Retriever.
2
Metadata Repo
Loads item_metadata.parquet → 3M item lookup table (title, author, genre, description, image_url, categories) into MetadataRepository.
3
Category Encoder
Loads or builds category_vocab.json from parquet. Maps book ASINs → leaf category integer IDs. PAD=0, UNK=1, sorted names from ID 2+. Powers DIF-SASRec.
4
Agent Pool
Builds 8 × DIFSASRecAgent instances (~148 MB each ≈ 1.18 GB total). Loads dif_sasrec_pretrained.pt as the cold-start snapshot. Pool backed by asyncio.Queue.
5
BGE-M3 Encoder
Loads BAAI/bge-m3 SentenceTransformer (1024-dim). Runs a warmup encoding pass. Used in /search and for profile vector computation.
6
CLIP Model
Loads openai/clip-vit-base-patch32 (512-dim image encoder + processor). Used in /search for visual query encoding and content veto in recommendations.
7
Search Engine
Initializes ActiveSearchEngine: loads Tantivy BM25 full-text index. Warms up NLLB-600M translation model. RRF fusion of FAISS + BM25 results ready.
8
Qwen LLM + MongoDB
Loads Qwen2.5-1.5B-Instruct locally. Opens Motor (async MongoDB) + Redis connections. Starts _log_worker asyncio task. Sets container.ready = True.
⚡ Background Worker: _log_worker
Runs as an asyncio.Task for the entire server lifetime. Drains Redis list "nba_interactions" into MongoDB one event at a time. When interaction count reaches CLEORA_REFIT_THRESHOLD, triggers _run_cleora_refit() asynchronously: re-trains Cleora Markov propagation → hot-swaps the FAISS Cleora index in memory without server restart.
After step 8: container.ready = True — require_ready() dependency starts returning 200 instead of 503. All routes become available.
AppContainer Fields · app/core/container.py

Single dataclass injected into every route via Depends(require_ready). Fields are write-once at startup.

retriever
faiss_repo.Retriever
HNSW · flat · Cleora FAISS indexes; BGE-M3/CLIP/Cleora vectors. reload_cleora() for hot-swap.
metadata_repo
metadata_repo.MetadataRepository
Parquet-backed item lookup: title, author, genre, description, image_url, cover_color.
profile_manager
profile_repo.UserProfileManager
User click history, aggregated embeddings, MongoDB persistence via Motor.
search_engine
active_search.ActiveSearchEngine
HNSW text + CLIP FAISS → Tantivy BM25 → RRF fusion. Used by POST /search.
recommend_engine
passive_recommend.PassiveRecommendationEngine
Pipeline A (Cleora) + Pipeline B (DIF-SASRec) orchestrator. Stateless — borrows agent from pool.
agent_pool
agent_pool.AgentPool
8 isolated DIFSASRecAgent instances. Borrow/return via asyncio.Queue. Prevents concurrent mutation.
category_encoder
category_encoder.CategoryEncoder
Leaf-category → integer ID. PAD=0, UNK=1. Used by Pipeline B and online training.
text_encoder
SentenceTransformer (BGE-M3)
1024-dim text encoder. Used in /search, /ask_llm, and profile embedding recompute.
clip_model / clip_processor
CLIPModel + CLIPProcessor
512-dim image encoder (ViT-B/32). Used in /search visual mode and content veto.
