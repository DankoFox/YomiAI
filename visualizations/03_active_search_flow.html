YomiAI Flows / 03 · Active Search

Active Search — POST /search

Multimodal search: text query (optionally Vietnamese) + optional image. Fuses semantic vector search with BM25 keyword ranking via RRF.

BGE-M3 [1024] CLIP [512] Tantivy BM25 RRF Fusion NLLB-600M
Pipeline Overview
①
NLLB Translation
app/infrastructure/translation.py
Detect language via Lingua. If Vietnamese (or non-EN), translate with NLLB-600M in thread executor. LRU-cached.
~5ms cached · ~274ms cold.
→
②
Parallel Encoding
app/core/models.py · anyio.TaskGroup
BGE-M3 text encoding and CLIP image encoding run concurrently via anyio.TaskGroup. Image skipped if no image_base64.
[1024] text [512] image
→
③
Dual FAISS + BM25
app/services/active_search.py
HNSW text index + CLIP HNSW index searched in parallel. Tantivy BM25 on raw query string. Three ranked lists fused via RRF.
→
④
Metadata Hydration
app/repository/metadata_repo.py
For each ASIN in fused results: metadata_repo.get_item(asin) → title, author, genre, description, image_url, cover_color, score breakdown.
Parallel Encoding Detail — Step ②
anyio.TaskGroup — runs both branches concurrently
BGE-M3 Text Encoder
Input: translated query string
Model: BAAI/bge-m3 (SentenceTransformer)
Output: [1024] float32 dense vector
Used in: HNSW text search + profile similarity
CLIP Image Encoder
Input: base64 image (decoded)
Model: openai/clip-vit-base-patch32
Output: [512] float32 dense vector
Skipped if no image provided → None
RRF Fusion Detail — Step ③
HNSW Text
1.7M vectors · BGE-M3 [1024]
top-K by cosine similarity
HNSW CLIP
3M vectors · CLIP [512]
top-K by cosine similarity
Tantivy BM25
Full-text index · raw query
title + description fields
→
RRF
Reciprocal Rank Fusion
score = Σ 1/(k+rank_i)
k=60 constant
If no image provided, CLIP search is skipped and RRF fuses only text FAISS + BM25 results.
Detailed Step Trace
  • 1
    translate_to_en(query) — runs NLLB-600M in loop.run_in_executor(). Returns original query if already English. Result cached via LRU cache keyed by query string.
  • 2
    Parallel via anyio.TaskGroup: encode_text(query, text_encoder) → [1024] float32  /  encode_image_b64(image_b64, clip_model, clip_processor) → [512] float32. Image branch skipped if no base64.
  • 3
    search_engine.search(user_id, text_vec, image_vec, query, top_k) — dispatches HNSW text, HNSW CLIP, and Tantivy BM25 internally. Returns fused list of (asin, score_dict) pairs.
  • 4
    For each ASIN: metadata_repo.get_item(asin) → adds title, author, genre, cover_color, image_url, bge_score, clip_score, rrf_score to result dict.
  • 5
    Return JSON response. live_encoding: true if a real-time encoding happened (vs. cached). query echoes the translated query string.
