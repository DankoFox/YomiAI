DIF-SASRec Model Architecture — Bottom to Top

Hover each layer to highlight. All layers in app/services/dif_sasrec.py.

Input
Embeddings
Item text embeddings [L × 1024] + position embeddings [L × 512] + category embeddings [L × cat_dim] summed as input to the first block.
seq [L × 1024]pos_emb [L × 512]cat_emb [L × cat_dim]
Layer 1
ContentProjector
Linear(1024 → 512) + LayerNorm + Dropout. Projects 1024-dim text embeddings into the 512-dim model space for the attention layers.
[L × 1024] → [L × 512]
Layer 2 (×4)
DIFAttentionLayer — Dual-Stream Attention
Two separate Q/K projections: Content stream (from projected text emb) and Category stream (from category emb). Attention scores from both streams are fused. Value (V) is always from content stream.
Q_content [L × 512]K_content [L × 512] Q_category [L × cat_dim]K_category [L × cat_dim] V [L × 512]out [L × 512]
Layer 3 (×4)
DIFSASRecBlock — Attention + FFN with Residuals
Pre-norm: LayerNorm → DIFAttentionLayer → residual. Then: LayerNorm → FFN(512→1024→512) → Dropout → residual. 4 such blocks stacked sequentially.
4 × blockFFN: 512→1024→512pre-norm + residual
Output
DIFSASRecModel — Intent Vector + Category Head
Takes the last-position hidden state [512] as the intent vector. A linear category_head projects it for the auxiliary category prediction task (used during training only).
intent [512]cat_logits [num_cats]
Agent
DIFSASRecAgent — Inference + Training
Wraps model + AdamW optimizer. get_candidate_scores(): runs forward pass → intent [512] → dot-product with projected candidate embeddings → scores. train_step(): sampled softmax loss + category auxiliary loss → backprop → AdamW step. Checkpoint saved to {user_id}_dif_sasrec.pt.
Dual-Stream Attention Detail
The key innovation of DIF-SASRec vs. standard SASRec: two separate attention streams computed independently, then fused. This lets the model decouple what the user reads (content) from what genre they're exploring (category).
Content Stream
Q, K: from ContentProjector output [L × 512]
V: also from ContentProjector output
Score: Q_c · K_cT / √512
Captures semantic similarity between positions in the click sequence.
Category Stream
Q, K: from category embeddings [L × cat_dim]
V: NOT used (value always from content)
Score: Q_cat · K_catT / √cat_dim
Captures genre-level intent signals. Helps when reading different genres sequentially.
Fusion: attn_score = content_score + α × category_score — α is a learned parameter. Softmax → weighted sum over V (content values). Output is passed through residual + FFN in each DIFSASRecBlock.
Scoring Computation
get_candidate_scores(click_seq, cat_ids, candidates)
1. Build item tensor: lookup BGE-M3 flat embeddings for each ASIN in click_seq → [L × 1024]
2. Forward pass through DIF-SASRec → intent vector [512] (last-position hidden state)
3. ContentProjector(candidate_embeddings) → candidate_proj [N × 512]
4. scores = intent @ candidate_proj.T → [N] dot products
5. min-max normalize → [0, 1] → sort descending → top-10
All tensor operations run on GPU (if available) via PyTorch. Agent is borrowed from AgentPool to prevent concurrent state mutation.
