Interact + Online Training — POST /interact

Logs a user action and, for click events, triggers one DIF-SASRec gradient step. The core online learning loop: every click trains the model on the user's actual next-item selection.

Three Action Types
not_interested
Dismiss Item
Writes item_id to Redis set user:{uid}:blocked. Returns immediately — no profile update, no training. Item will be filtered from all future recommendations.
skip
Soft Interaction
Appends to purchases list only. No embedding update, no training gradient. Logged to Redis queue → MongoDB for analytics. Useful for tracking page-views without full engagement.
click
Full Engagement → Training
Full profile update: append to clicks deque, recompute text/visual/cleora profiles with exponential decay, MongoDB upsert. Triggers one DIF-SASRec gradient step. Saves .pt checkpoint.

Training Step Detail — One Gradient Update
train_personal(user_id, item_id, agent, click_seq_before)
  • 1
    Build tensors: _build_tensors(click_seq_before, item_id) → item content embeddings [L×1024] + category IDs [L] + positive item ASIN.
  • 2
    Forward pass: DIF-SASRec → intent vector [512]. ContentProjector(pos_item_emb) → positive candidate projection [512].
  • 3
    Negative sampling: sample 512 random ASINs from catalogue. retriever.text_flat.reconstruct_batch(neg_ids) → neg embeddings [512 × 1024] → project to [512 × 512].
  • 4
    Sampled softmax loss: intent · [pos_proj; neg_projs].T → logits [513] → cross-entropy with label 0 (positive at index 0).
  • 5
    Category auxiliary loss: category_head(intent) → logits [num_cats] → cross-entropy vs. true leaf category of clicked item. Weighted sum of both losses.
  • 6
    Backprop + AdamW step: loss.backward() → optimizer.step() → optimizer.zero_grad(). Append loss to agent.loss_history (max 200 entries).
